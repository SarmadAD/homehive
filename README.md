# 🏡 HomeHive

**HomeHive** ist eine digitale Plattform für private Vermieter und kleine Hausverwaltungen. Ziel ist es, die Immobilienverwaltung zu vereinfachen, Mieteingänge im Blick zu behalten und die Kommunikation mit Mietern zu verbessern.

---

## ✨ Features

- 📋 Verwaltung von Immobilienobjekten
- 👥 Verwaltung von Mietern mit Zuordnung zu Objekten
- 💸 Erfassung und Nachverfolgung von Mieteinnahmen
- 🧑‍💻 Vermieter- und Mieterportal mit separaten Zugängen
<!--- 🔔 Erinnerungen bei fehlenden Mietzahlungen
🔐 Integration von Banking APIs durch Plaid zur automatischen Erkennung von Mieteingängen
--->


---

## 🚀 Tech Stack

- Frontend: React (Next.js, Vercel Deployment)
- Backend: Node.js / Serverless Functions
- Auth: z. B. Supabase Authentication and Auth Guards
- Datenbank: Supabase and Prisma as ORM

---

## 🛠️ Setup

```bash
git clone https://github.com/dein-benutzername/homehive.git
```
